# Sistema de Recomendação de Jogadores de Futebol

MVP desenvolvido como parte de um Trabalho de Conclusão de Curso em Ciência da Computação.

O projeto tem como objetivo utilizar dados estatísticos de jogadores de futebol para identificar atletas com características semelhantes a um jogador utilizado como referência.

## Status

Em desenvolvimento.

- Pandas
